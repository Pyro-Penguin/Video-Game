# Expanded Damage Sensitivity Experiment

This experiment extends the initial paired-profile study with the pre-registered all-vs-all matrix, combined-stat perturbations, Candidate B offset sweep, two level-treatment paths, and a Pokémon Generation IX reference harness.

**Status:** Synthetic investigation only. No equation, stat range, level policy, or TTK target is approved.

## Synthetic inputs

- Attacker profiles: Balanced 300/275; Offensive 400/250; Defensive 250/350; High-pressure 400/200; Low-pressure 200/350.
- Independent defender sweep: Defense 200, 250, 275, 300, and 350 (five distinct coordinates; not aliased to the attacker profiles).
- Five attacker profiles × five defender profiles = 25 ordered matchups.
- Vitality: 250, 350, 500. Ordinary reference power: 100.
- Competitive comparison level: 100. Level 50 is retained as the historical calibration anchor.
- Story-level diagnostic sweep: 1, 5, 10, 25, 50, 75, 100.
- Candidate B offsets: absolute c = 0, 25, 50, 100, 200, 400; scale-relative c = 71 and 143 (25% and 50% of the arithmetic mean of neutral-reference Attack 300 and Defense 275).

All profiles and values are synthetic test coordinates, not final creatures, classes, stat ranges, or approved game rules.

## Experiment contents

1. **All-vs-all matrix:** every attacker profile against every defender profile at each Vitality point. Damage candidates A–D are calibrated to 60 damage at Level 100, Power 100, Attack 300, Defense 275. Each Candidate B offset is independently calibrated to the same anchor.
2. **Combined-stat perturbations:** Attack×Defense, Attack×Vitality, Defense×Vitality, and Attack×Defense×Vitality. Each participating stat receives the same −20%, −10%, −5%, +5%, +10%, or +20% change, plus baseline. Single-stat controls are included so pair/triple interaction residuals can be calculated. The raw-damage interaction residual is defined in log space: log(combined damage ratio) minus the sum of isolated log ratios. Zero indicates multiplicatively separable effects; nonzero values measure interaction. A separate single-stat TTK-shift table reports isolated Attack, Defense, and Vitality changes against baseline. Exact Fraction ratios are retained until the logarithm is evaluated. The floored-TTK residual remains a discrete, flooring-sensitive diagnostic. Integer stat values are floored and actual values are reported.
3. **Level treatment:** level-derived-only candidates hold derived stats constant across level; Candidate C measures a separate direct-level term. The story sweep includes all seven specified levels.
4. **Pokémon reference harness (audit-only):** deterministic Generation IX base-damage core with fixed 100% random factor. It is never a selectable candidate, is not part of candidate ranking or pruning, and is not calibrated to the game's candidate anchor. STAB, type, criticals, weather, items, abilities, screens, and other modifiers are excluded.
5. **Candidate B offset study:** reports neutral TTK, clean 2:1 Attack/Defense response, full-Vitality one-hit behavior, and per-matchup floored TTK spread for each c.
6. **Rank/floor audit:** reports raw and floored candidate ordering for each matchup, including pairwise rank flips and tie changes across all Candidate B offsets. Aggregate order is supplemental, never a substitute for matchup-level rank changes.

## Pre-registered screening gates

The gates are applied before any candidate pruning and use integer-floored per-hit damage and floored TTK. Raw outputs are diagnostic only.

- Historical neutral reference: Balanced attacker (300 Attack), Balanced defender (275 Defense), Vitality 350, Power 100, Level 100. The former 4–6-hit target is superseded by D-026's competitive 2–3-hit pacing references.
- 2:1 Attack/Defense specialization ratio: 1.4×–1.8× relative to equal stats, swept across every pre-registered defender profile. The gate requires both the worst-case minimum and best-case maximum to remain inside the band; a single Defense=300 coordinate is insufficient.
- No ordinary Power-100 one-hit KO against the full-Vitality neutral reference.
- Attack increases cannot reduce damage; Defense increases cannot increase damage; Vitality increases cannot reduce TTK.
- Any ±1-hit TTK tolerance is checked on floored results, never raw TTK.
- Candidate B c values are not fitted per matchup. The same gates apply to all offsets; rank instability is reported rather than tuned away.

Combined changes can push different dimensions in opposing directions, so they are reported as interaction results rather than forced into a single monotonic pass/fail.

## Run

From repository root:

```bash
cd experiments/stat_range_sensitivity
python3 stat_range_sensitivity.py --output /tmp/report-v2.json
python3 -m unittest -v
```

The report is JSON and is generated by CI as an artifact. Shared raw candidate functions live in experiments/common/damage_candidates.py; this experiment supplies its own explicit 60-damage Level-100 calibration anchor from config.json. Exact rational arithmetic is used for candidate equations; gameplay damage is floored per hit with a minimum of 1. The Generation IX reference harness uses exact integer floor operations in its deterministic base-damage core.

## Hypothetical roll-pacing diagnostic

The generated report also evaluates a **hypothetical** uniform set of fixed roll percentages from 85% through 100%, inclusive. For each Defense coordinate, it applies each percentage to exact candidate damage, floors damage once, and computes the resulting deterministic hits-to-KO. The guaranteed 4–6 containment result passes only when every roll at every registered Defense profile produces 4–6 hits. The report also provides `mean_fixed_roll_ttk`, the arithmetic mean of those fixed-roll deterministic TTKs; this is not the expected stopping time when independent rolls occur on successive hits.

This diagnostic does not select an RNG distribution, change the D-022 deterministic neutral pacing gate, or change the 60-damage calibration anchor. The alternate-anchor counterexample is included only to show that a full-band failure at anchor 60 does not prove that every candidate is incompatible with the pacing interval at every possible calibration. No alternate anchor is selected.

## Interpretation limits

- This is not a complete battle damage pipeline. It excludes type effectiveness, STAB, RNG variation, criticals, equipment, abilities, status, shields, multi-hit, simultaneous damage, and application to battle state.
- The Pokémon-style implementation is a mechanical reference harness only, not a candidate and not evidence of desired balance.
- The level-derived-only path isolates direct level dependence by holding derived stats fixed; it does not model actual stat progression.
- The five profiles are test coordinates, not validated play styles.
- Passing tests establish implementation consistency, not game balance or human acceptance.
- The raw-damage interaction residual uses a log-space multiplicative definition. The separately named interaction_ttk_delta_vs_additive is a combined-versus-additive TTK interaction, not an isolated single-stat shift. Use single_stat_ttk_shifts for isolated shifts. Sequential integer floors in the Generation IX reference are mathematically equivalent to the combined denominator floor for positive integer inputs.


**Status note (2026-10-31):** The 4–6-hit pacing target and 85%–100% fixed-roll diagnostic documented here are historical and superseded for current design decisions by D-026 (competitive 2–3-hit pacing references) and D-027 (85%–105% inclusive RNG bounds). This experiment is retained as evidence; do not expand its matrix or treat its old gate as current acceptance criteria.
