# Video Game

## First Executable Experiment
[Damage RNG Experiment](experiments/damage_rng/README.md) — standalone Python 3.10+ experiment with exact single-hit KO enumeration, seeded repeated-hit simulation, JSON reporting, and automated tests.

## Project Principle
Ideas, experiments, and approved rules are kept separate. Experimental results do not become game rules without an explicit design decision.
