# Art Direction Reference Library

**Status:** Open collection for visual research and inspiration. References inform an original visual identity; they are not instructions to reproduce another game's, studio's, or artist's protected style.

## Add images here

Place image files in this folder. Suggested formats: PNG, JPG/JPEG, and WebP. Use descriptive filenames, for example:

- `environment-village-silhouette-reference.jpg`
- `lighting-warm-dusk-atmosphere.png`
- `camera-overworld-composition.jpg`
- `creature-shape-language.webp`
- `ui-battle-readability.png`

## For each reference, record where possible

Add a short entry below or in a neighboring Markdown note:

- **File:** image filename
- **Source:** original URL, game/art book/artist, or creator
- **Attribution / rights:** creator and known license or usage restrictions; mark unknown when unknown
- **What to study:** composition, palette, lighting, silhouette, materials, camera, mood, animation, or visual storytelling
- **What not to copy:** distinctive characters, designs, exact compositions, logos, or other protected expression
- **Project application:** the original design question this reference may help answer

Do not assume that an image found online is licensed for reuse. These images are research references unless usage rights are explicitly established.

## Initial visual questions

- How should the stylized 3D world balance readable forms with painterly atmosphere?
- How should the overworld camera communicate scale, belonging, and discovery?
- How should battle camera transitions feel continuous with exploration?
- How can lighting, color, framing, posture, and negative space communicate story without dialogue?
- How should each village feel distinct while belonging to one coherent world?

## Curation rule

Keep useful contrasting references, not just images that all share one look. Add a note about the specific quality being studied; do not treat a reference as an accepted direction until it has been reviewed and recorded in the relevant design document.


## Folder structure

Use the category folders below to keep references discoverable. Each folder contains an intake guide; place source images and attribution notes beside the references they describe.

- `Character & NPC/`
- `Creature/`
- `Armor & Weapons/`
- `Environment/`
- `Lighting/`
- `VFX/`
- `UI/`

Keep the source, creator, rights status, and visual question being studied with every reference. References are research material, not cleared production content.
